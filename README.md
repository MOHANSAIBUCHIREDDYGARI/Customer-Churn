# 📊 Customer Churn Prediction Dashboard

A machine-learning powered churn prediction web application where users upload a CSV file and receive:
- Churn probability predictions
- Risk level categorization
- Interactive dashboards & visualizations
- High-risk customer prioritization
- Downloadable output CSV

## 🚀 Features
- Upload CSV dataset
- Predict churn for each customer
- View KPI Cards for risk segmentation
- Beautiful visual dashboards
- Export results to CSV

## 🛠 Tech Stack
- Python
- Streamlit
- Scikit-Learn
- Pandas / NumPy / Seaborn / Matplotlib
